# Cyber Miner v4.0

原生 HTML / CSS / JavaScript 实现的赛博放置游戏：点击挖矿、自动生产、Boss 战、装备、合成、技能、成就、每日任务与宝箱。

## 运行

无需安装前端依赖。在项目目录启动静态服务器：

```sh
python -m http.server 8000
```

浏览器打开 http://localhost:8000 。存档保存在当前浏览器、当前站点的 localStorage 中。更换端口、浏览器或设备前，请导出存档。

## v4.0 新增

- 离线生产：离开至少 60 秒后，下次加载按自动算力的 50% 结算，最多 8 小时。算力包含永久升级和装备，不含临时 Buff、暴击、战斗和掉落；离线收益不计入当天任务。旧存档首次升级仅建立时间戳，不补算历史收益。
- 商店批量购买：×1、最多 ×10、最多 ×100、最大可购买。按每一级实际价格递增扣费，余额不足时购买能负担的数量。
- 指挥中心：查看关卡、累计点击、累计收益、Boss 击杀、暴击和成就数量。
- 存档管理：手动保存、JSON 导入导出、导入前自动备份和恢复。导入会校验结构并重建物品显示信息；导入和恢复均从当前时间开始计算离线时间。支持旧版 v3 存档，不支持未知版本。
- 减少动画和飘字开关，保存在本地；支持系统减少动态效果偏好。
- 核心支持键盘操作：Tab 聚焦后按空格或回车，长按不重复触发。
- 手机导航支持横向滚动；按钮增加键盘焦点提示。

同时修复基础算力技能未正确作用于购买设备的问题、Boss 奖励技能错误影响普通怪物的问题，以及跨午夜每日任务未及时刷新的问题。离线收益只在重新加载时结算，不对后台打开的标签页额外补偿。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` / `style.css` | 页面和样式 |
| `script.js` | 游戏引擎和原有玩法 |
| `enhancements.js` | 批量购买、离线结算、统计、存档管理和设置 |
| `config.js` | 商店与战斗参数 |
| `loot-config.js` | 装备与掉落 |
| `features-config.js` | 技能、任务、成就、宝箱等配置 |

## 验证

Node.js 18+，不需要安装依赖：

```sh
node --test tests/features.test.cjs
node --check script.js
node --check enhancements.js
```

回归用例覆盖离线时间边界、8 小时上限、递增价格、余额限制、旧存档兼容、异常数据拒绝与装备显示字段清理。

发布前可在浏览器手动验证：切换八个页面、键盘挖矿、批量购买、导出后重新导入、恢复备份、开启减少动画后刷新，以及手机窄屏下滚动导航。
